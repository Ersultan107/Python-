01 · Проблема

Метро без турникета

Счёт · Арсен · **** 4821
100 000 ₸
class BankAccount:
    def __init__(self, balance):
        self.balance = balance

account = BankAccount(100000)
account.balance = -50000
print(account.balance)
Простыми словами: balance лежит на виду, как платформа без турникета. Кто угодно может записать туда любое число, и никто не проверит.
-50000 — проблема! Баланс изменён напрямую, и Python ничего не проверил.
02 · Решение

Собери турникет сам

Выбери правильные значения в пропусках. Верный ответ встаёт на место.

Как это работает: self.__balance — баланс карты, спрятанный в классе. withdraw() — турникет: if проверяет два условия (сумма больше нуля, денег хватает). Если оба верны, деньги списываются и метод возвращает True. Иначе False, и баланс не меняется.

  
Турникет установлен! Теперь баланс меняется только через проверку. Двойное подчёркивание лишь затрудняет прямой доступ: это порядок на входе, а не абсолютная защита.

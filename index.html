while True: — «бесконечно повторяй меню». Условие True всегда верно, поэтому цикл сам не закончится. break — «полностью выйти из цикла»: он срабатывает только при выборе 6.



Функции и return


Важно про этот код: в главном цикле написано buy_ticket(seats, ticket_count, paid_money) — без x = …. Значит, число, которое вернула функция (return price или return 0), никуда не сохраняется и дальше не используется. Работа функции видна по другому: она сама изменила списки и сама напечатала текст. Это нормально — в этом решении return просто «заканчивает функцию».

Можно было бы писать cash = cash + buy_ticket(...) и хранить сумму в переменной. Но в твоём решении так не сделано, и менять ничего не нужно.
